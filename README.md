# 🎵 Music Player Website

A clean, modern music player web app built with React and Vite — create playlists, control playback, and adjust volume with a smooth, responsive interface.

## Features

- ▶️ Play, pause, skip, and scrub through tracks with a custom progress bar
- 🎧 Create and manage multiple playlists
- 🔍 Search and add songs to a playlist from your library
- 🔊 Adjustable volume control
- 📱 Responsive layout that works across screen sizes
- 🎨 Custom-styled UI with smooth transitions and hover states

## Tech Stack

- **React** — component-based UI
- **Vite** — fast dev server and build tooling
- **ESLint** — code quality and consistency

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/BishalLamichhane777/Music-Player-Website.git
cd Music-Player-Website
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
